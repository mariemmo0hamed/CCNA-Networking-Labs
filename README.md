CCNA Networking Labs

A hands-on networking portfolio documenting my practical experience with Cisco networking technologies and network infrastructure implementation.

This repository contains a collection of networking labs designed and implemented using GNS3, focusing on CCNA concepts, network configuration, routing, switching, and troubleshooting.

Tools & Technologies

- GNS3: Network simulation and topology design.
- Cisco IOS: Router and switch configuration.
- VMware Workstation: Virtualization environment.
- Networking Protocols: TCP/IP, IPv4, IPv6, and various routing and switching protocols.

Topics Covered

- Switching: VLANs, Access Ports, Trunking, STP, and EtherChannel.
- Routing: Static Routing, Default Routing, and Dynamic Routing.
- OSPF: Single-Area and Multi-Area OSPF.
- Network Services: DHCP and other network services.
- Tunneling: GRE Tunneling.
- Network Troubleshooting: Connectivity testing, configuration verification, and fault isolation.
- IP Addressing: IPv4 and IPv6 addressing and subnetting.

Repository Structure

Each lab is organized in its own directory and includes:

- GNS3 Project Files: Complete project files for opening and running the lab.
- Network Topology: Visual representation of the network design and device connections.
- Router Configurations: Running configurations for routers.
- Switch Configurations: Running configurations for switches.
- Lab Documentation: A dedicated README explaining the lab objectives, topology, implementation, and configurations.

Learning Objectives

- Develop practical Cisco networking configuration skills.
- Understand network architecture and device communication.
- Implement and troubleshoot routing and switching technologies.
- Gain hands-on experience with network simulation and infrastructure design.
- Build a strong foundation for advanced networking technologies.
